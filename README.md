# AI Pathfinder – Uninformed Search Visualization

## Course
AI 2002 – Artificial Intelligence

## Project Description
This project implements and visualizes uninformed search algorithms in a grid-based environment. The application allows an agent to move from a Start node to a Target node while avoiding obstacles. The search process is animated step by step to demonstrate how each algorithm explores the grid.

The graphical interface is developed using Pygame and provides a clear visual distinction between frontier nodes, explored nodes, walls, and the final path.

## Algorithms Implemented
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Uniform Cost Search (UCS)
- Depth Limited Search (DLS)
- Iterative Deepening Depth First Search (IDDFS)
- Bidirectional Search

## Features
- Interactive grid generation
- Step-by-step visualization of search process
- Color representation for different node states
- Mouse-based placement of start, target, and obstacles
- Keyboard controls for running different algorithms
- Grid reset functionality
